# LinkUp App

**LinkUp** is a Flutter-based chat application that seamlessly connects you with friends, family, and communities—all in one place. The app is powered by Firebase, ensuring real-time communication and data synchronization.

---

## ✨ Features

- **Onboarding Screens**  
  An engaging introduction to guide new users through the app's features.

- **User Authentication**  
  - Sign up and log in securely with Firebase Authentication.  
  - Email verification for added security.  

- **Chats Screen**  
  - View all registered and verified users.  
  - Search for specific users.  
  - Start a conversation with a sleek and responsive chat UI.  
  - Persistent chat storage for continuous and uninterrupted conversations.

- **Settings Screen**  
  - Update user profile information.  
  - Change profile picture with ease.
